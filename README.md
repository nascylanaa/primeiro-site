# Cineterror

Site fictício sobre filmes de terror desenvolvido para a atividade de HTML e CSS.

## Estrutura do Site
- index.html: Página inicial com a apresentação do site.
- recomendacoes.html: Segunda página contendo a lista de filmes recomendados.
